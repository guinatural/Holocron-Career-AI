# PRD - Resumo Executivo

## Visão

Plataforma SaaS multi-tenant para gestão de carreira com agentes de IA, conectando vagas, candidaturas e desenvolvimento profissional.

## Problema

Profissionais enfrentam:
- Sobrecarga de candidaturas sem feedback
- Falta de personalização em currículos e cartas
- Dificuldade em rastrear progresso
- Ausência de recomendações baseadas em dados

## Solução

Plataforma com:
- **8 Agentes de IA** para automação inteligente
- **Matching 0-100** com explicação RAG
- **Pipeline visual** (Kanban)
- **Feedback contínuo** com insights

## Limites

- **Não é** headhunter (não entra em contato com recrutadores)
- **Não é** plataforma de cursos (recomendações externas apenas)
- **Não é** CRM para empresas (apenas para candidatos)

## Sucesso

- 500 candidaturas gerenciadas por usuário
- 80% de matching > 70
- 40% de redução no tempo de emprego
- 90% de satisfação (NPS)

## LGPD

- Consentimento explícito
- Right to be forgotten
- Data portability (export JSON)
- Audit trail para todas as ações
